## Fitur Utama Tema
* **Header & Menu Navigasi:** Bagian atas website yang dilengkapi judul, deskripsi, dan menu utama yang dinamis.
* **Gambar Unggulan (Featured Image):** Mendukung foto atau gambar menarik di setiap postingan artikel.
* **Halaman Depan & Blog (Index & Archive):** Menampilkan daftar artikel terbaru secara rapi dan otomatis menggunakan sistem *The Loop*.
* **Halaman Baca Penuh (Single Post):** Tampilan khusus saat pembaca mengklik artikel untuk membaca isi secara lengkap.
* **Sidebar Samping:** Dilengkapi kotak pencarian artikel (*Search*) dan daftar artikel terbaru.
* **Tampilan Responsif:** Nyaman dilihat dan otomatis menyesuaikan layar komputer maupun handphone.

## Cara Menjalankan / Instalasi Tema di Komputer
1. **Unduh Folder Tema:** Download seluruh file dalam repository ini (atau clone).
2. **Pindahkan Folder:** Letakkan folder **`theme-saya`** ke dalam direktori penyimpanan WordPress lokal kamu di komputer:
   `C:\xampp\htdocs\pemrogramancms\wordpress\wp-content\themes\`
3. **Buka Dashboard WordPress:** Buka browser lalu masuk ke halaman admin WordPress kamu di:
   `http://localhost/pemrogramancms/wordpress/wp-admin/`
4. **Aktifkan Tema:** 
   * Masuk ke menu sebelah kiri: **Tampilan (Appearance) > Tema (Themes)**.
   * Cari tema bernama **Theme Saya**, lalu klik tombol **Aktifkan (Activate)**.
5. Selesai! Website WordPress sudah menggunakan tema baru.
