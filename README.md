# Theme Saya - WordPress Theme (Tugas Pemrograman CMS)

## Deskripsi Tema
**Theme Saya** adalah tema WordPress sederhana, modern, dan responsif yang dirancang khusus untuk memenuhi tugas Ujian Tengah Semester (UTS) mata kuliah Pemrograman CMS. ## Fitur Tema
- **Header & Navigasi:** Menu utama dinamis yang terhubung dengan WP Menus.
- **Featured Image Support:** Menampilkan gambar unggulan pada postingan artikel.
- **Single Post & Archive:** Halaman detail baca artikel penuh dan arsip kategori.
- **Sidebar Widget:** Bagian pencarian artikel dan daftar artikel terbaru.
- **Responsive Design:** Menyesuaikan dengan baik pada perangkat desktop maupun seluler.

## Petunjuk Instalasi
1. Unduh atau clone folder tema ini.
2. Letakkan folder `theme-saya` ke direktori WordPress lokal Anda di:
   `C:\xampp\htdocs\pemrogramancms\wordpress\wp-content\themes\`
3. Buka dashboard WordPress admin (`http://localhost/pemrogramancms/wordpress/wp-admin/`).
4. Masuk ke menu **Tampilan (Appearance) > Tema (Themes)**.
5. Cari tema **Theme Saya**, lalu klik **Aktifkan (Activate)**.
